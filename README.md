# TheVine_ExamCode
- Usability and testing notes:
The churches are marked with black crosses, please zoom in over an area to see them.

- Note:
I scaled down the size of the project from displaying the whole Bible to simply displaying 2 books in response to technical complexity, time constraints and API integration challenges.

The Bible reader was limited to Psalms and Proverbs to provide a more focused devotional experience centred on spiritual encouragement and practical wisdom. Translation switching, personal study notes, bookmarks and user profiles were removed from the final scope to prioritise the reliability of core functionality.

The project consequently focuses on three primary experiences: exploring the platform, engaging with Scripture and discovering Christian communities and digital media.

This decision allowed development efforts to prioritise API integration, meaningful GSAP animations, responsive design, accessibility and visual consistency over a larger collection of partially implemented features.

The removed features remain potential opportunities for future development.
